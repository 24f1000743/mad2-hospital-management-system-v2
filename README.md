# Hospital Management System - V2

Course project for MAD-II.

## Features
- Admin, Doctor, Patient dashboards
- JWT authentication & RBAC
- Appointment system
- Celery background jobs
- Redis integration

## Tech Stack
- Backend: Flask
- Frontend: Vue.js
- Database: SQLite
- Queue: Celery + Redis

## Setup
1. Create venv and install requirements
2. Start Redis
3. Run Flask server
4. Run Vue frontend
5. Start Celery worker
